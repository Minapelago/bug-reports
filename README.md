# Minapelago bug reports

This repo is the issue tracker for the Mina the Hollower Archipelago randomizer. It holds no code.

Found a bug? [Open a bug report](https://github.com/Minapelago/bug-reports/issues/new?template=bug_report.yml).

The code lives in [Minapelago/client](https://github.com/Minapelago/client) (the game mod) and [Minapelago/world](https://github.com/Minapelago/world) (the APWorld).
